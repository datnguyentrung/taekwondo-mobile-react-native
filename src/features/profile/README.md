# Profile

Feature này sở hữu hồ sơ người dùng, thông tin cá nhân và các thao tác cập nhật hồ sơ.

Chỉ tạo các thư mục như `api`, `components`, `domain`, `hooks`, `screens`, `schemas` hoặc
`__tests__` khi có code thực tế cần trách nhiệm tương ứng. Kiểu dữ liệu transport và domain cần
được tách riêng khi chúng có ý nghĩa khác nhau.
