# Attendance

Feature này sở hữu nghiệp vụ điểm danh, lịch sử điểm danh và các quy tắc liên quan đến buổi tập.

Chỉ tạo các thư mục như `api`, `components`, `domain`, `hooks`, `screens`, `schemas` hoặc
`__tests__` khi có code thực tế cần trách nhiệm tương ứng. Hạ tầng dùng chung phải được đặt ngoài
feature sau khi có nhu cầu tái sử dụng được chứng minh.
