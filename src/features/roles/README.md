# Authentication

Feature này sở hữu luồng xác thực, phiên đăng nhập và các quy tắc phân quyền của người dùng.

Chỉ tạo các thư mục như `api`, `components`, `domain`, `hooks`, `screens`, `schemas` hoặc
`__tests__` khi có code thực tế cần trách nhiệm tương ứng. Không đặt logic của `attendance` hay
`profile` trong feature này.
